# Интеграция Astarta Capital с WordPress

Этот документ описывает, как интегрировать статический сайт Astarta Capital с WordPress для обработки форм.

## Структура файлов

```
/workspace/
├── src/                          # Оригинальные файлы статического сайта
├── wordpress-theme/              # WordPress тема
│   ├── functions.php            # Функции темы и AJAX обработчики
│   ├── index.php                # Главная страница темы
│   ├── style.css                # Стили темы
│   └── templates/               # Шаблоны (header, form, etc.)
├── wordpress-form-handler.php   # Отдельный обработчик форм (альтернатива)
└── WORDPRESS_INTEGRATION.md     # Этот файл
```

## Способы интеграции

### Способ 1: WordPress тема (Рекомендуется)

1. **Установите WordPress** на ваш сервер
2. **Скопируйте папку `wordpress-theme`** в `/wp-content/themes/astarta-capital/`
3. **Активируйте тему** в админ-панели WordPress
4. **Скопируйте все ресурсы** (изображения, видео, аудио, шрифты) в папку темы
5. **Настройте пути** к ресурсам в `index.php`

### Способ 2: Отдельный обработчик форм

1. **Установите WordPress** на ваш сервер
2. **Скопируйте `wordpress-form-handler.php`** в корень WordPress
3. **Обновите JavaScript** для отправки на правильный URL
4. **Настройте права доступа** к файлу

## Настройка

### 1. Настройка путей к ресурсам

В файле `wordpress-theme/index.php` обновите пути к ресурсам:

```php
// Замените эти пути на правильные
src="<?php echo get_template_directory_uri(); ?>/video/output.mp4"
src="<?php echo get_template_directory_uri(); ?>/images/site-title.png"
// и т.д.
```

### 2. Настройка email уведомлений

В файле `wordpress-theme/functions.php` настройте email адреса:

```php
$admin_email = get_option('admin_email'); // Email администратора
```

### 3. Настройка безопасности

Убедитесь, что nonce правильно передается в JavaScript:

```javascript
// В functions.php
wp_localize_script('astarta-main', 'astartaAjax', array(
    'ajaxurl' => admin_url('admin-ajax.php'),
    'nonce' => wp_create_nonce('contact_form_nonce'),
    'contactFormNonce' => wp_create_nonce('contact_form_nonce')
));
```

## Функциональность

### Обработка форм

- ✅ Валидация данных на стороне сервера
- ✅ Валидация данных на стороне клиента
- ✅ Сохранение заявок в базу данных
- ✅ Отправка email уведомлений администратору
- ✅ Отправка подтверждения пользователю
- ✅ Защита от CSRF атак (nonce)
- ✅ Санитизация входных данных

### Админ-панель

- ✅ Просмотр всех заявок
- ✅ Фильтрация по дате
- ✅ Экспорт данных
- ✅ Управление статусами заявок

### База данных

Автоматически создается таблица `wp_contact_submissions` со следующими полями:

- `id` - уникальный идентификатор
- `first_name` - имя
- `last_name` - фамилия
- `phone` - телефон
- `email` - email
- `submitted_at` - дата отправки
- `ip_address` - IP адрес
- `user_agent` - информация о браузере
- `status` - статус заявки

## Безопасность

1. **Nonce защита** - предотвращает CSRF атаки
2. **Санитизация данных** - очищает все входные данные
3. **Валидация** - проверяет корректность данных
4. **Escape вывод** - безопасный вывод данных
5. **Проверка прав** - только администраторы могут просматривать заявки

## Тестирование

1. **Отправьте тестовую форму** с корректными данными
2. **Проверьте email уведомления** в почте администратора
3. **Проверьте сохранение** в админ-панели WordPress
4. **Протестируйте валидацию** с некорректными данными

## Поддержка

При возникновении проблем:

1. Проверьте логи ошибок WordPress
2. Убедитесь в правильности путей к ресурсам
3. Проверьте настройки email
4. Убедитесь в корректности nonce

## Дополнительные возможности

### Интеграция с CRM

Можно легко интегрировать с популярными CRM системами, добавив соответствующие API вызовы в функцию `handle_contact_form_ajax()`.

### Аналитика

Добавьте Google Analytics или другие системы аналитики для отслеживания конверсий форм.

### A/B тестирование

Используйте WordPress плагины для A/B тестирования различных вариантов форм.
