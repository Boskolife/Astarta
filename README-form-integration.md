# Интеграция формы Astarta Capital с WordPress

Это руководство поможет вам интегрировать форму обратной связи с WordPress для сайта Astarta Capital.

## Компоненты решения

### 1. PHP Обработчик (`form-handler.php`)
- Автономный обработчик формы, работает как с WordPress, так и без него
- Валидация данных на сервере
- Сохранение в базу данных
- Отправка email уведомлений
- Защита от спама и дубликатов

### 2. WordPress Плагин (`astarta-contacts-plugin.php`)
- Полнофункциональный плагин для WordPress
- Админ панель для управления заявками
- Статистика и аналитика
- Экспорт данных в CSV
- Система статусов заявок

### 3. JavaScript обработчик (в `main.js`)
- AJAX отправка формы
- Валидация на клиенте
- Красивые уведомления
- Обработка ошибок

### 4. CSS стили (в `_form.scss`)
- Стили для ошибок валидации
- Анимации уведомлений
- Адаптивный дизайн

## Варианты установки

### Вариант 1: Использование WordPress плагина (Рекомендуется)

1. **Установка плагина:**
   ```bash
   # Скопируйте файлы плагина в папку плагинов WordPress
   cp astarta-contacts-plugin.php /path/to/wordpress/wp-content/plugins/astarta-contacts/
   cp -r includes/ /path/to/wordpress/wp-content/plugins/astarta-contacts/
   cp -r assets/ /path/to/wordpress/wp-content/plugins/astarta-contacts/
   ```

2. **Активация:**
   - Зайдите в админ панель WordPress
   - Перейдите в "Плагины" → "Установленные плагины"
   - Найдите "Astarta Contacts Manager" и активируйте

3. **Настройка:**
   - После активации в админ меню появится раздел "Astarta Contacts"
   - Плагин автоматически создаст необходимую таблицу в базе данных
   - Форма будет работать через AJAX с WordPress

### Вариант 2: Автономный обработчик

1. **Установка:**
   ```bash
   # Скопируйте обработчик в корень сайта или в папку с формой
   cp form-handler.php /path/to/your/website/
   ```

2. **Настройка:**
   - Убедитесь, что путь к `wp-load.php` корректен в файле `form-handler.php`
   - При необходимости измените пути в массиве `$possible_paths`

## Настройка формы

### HTML структура
Ваша форма уже имеет правильную структуру. Убедитесь, что у неё есть:
- `id="contact-form"`
- Поля с именами: `firstName`, `lastName`, `email`, `phone`
- Кнопка отправки с типом `submit`

### JavaScript инициализация
JavaScript код уже добавлен в `main.js`. Он автоматически:
- Определяет, работает ли WordPress
- Выбирает правильный URL для отправки
- Обрабатывает ответы сервера

## Функции

### Валидация
- **Клиентская:** JavaScript проверяет поля перед отправкой
- **Серверная:** PHP дополнительно валидирует все данные

### Защита от спама
- Проверка nonce токенов
- Ограничение на повторные отправки (1 час)
- Валидация IP адресов
- Санитизация всех входных данных

### Email уведомления
- **Администратору:** Подробная информация о заявке
- **Клиенту:** Подтверждение получения заявки

### Админ панель (только для плагина)
- Просмотр всех заявок
- Фильтрация по статусу и поиск
- Изменение статусов заявок
- Экспорт в CSV
- Статистика по дням и статусам

## Статусы заявок

- **new** - Новая заявка
- **processing** - В работе
- **completed** - Завершена
- **cancelled** - Отменена

## Настройка email

### Изменение email получателя
```php
// В form-handler.php или includes/class-form-handler.php
$this->admin_email = 'your-email@example.com'; // Вместо get_option('admin_email')
```

### Настройка SMTP (рекомендуется)
Для надёжной доставки email используйте SMTP плагин:
- WP Mail SMTP
- Easy WP SMTP
- Post SMTP

## Кастомизация

### Изменение текстов уведомлений
Отредактируйте методы `send_email_notification()` и `send_client_confirmation()` в обработчике.

### Добавление новых полей
1. Добавьте поле в HTML форму
2. Обновите валидацию в JavaScript и PHP
3. Добавьте поле в базу данных (для плагина)

### Изменение стилей
Отредактируйте файл `src/styles/components/_form.scss`

## Безопасность

## Отладка

### Включение логирования
```php
// В wp-config.php
define('WP_DEBUG', true);
define('WP_DEBUG_LOG', true);
define('WP_DEBUG_DISPLAY', false);
```

### Проверка логов
```bash
# Логи WordPress
tail -f /path/to/wordpress/wp-content/debug.log

# Логи веб-сервера
tail -f /var/log/apache2/error.log
# или
tail -f /var/log/nginx/error.log
```

### Тестирование формы
1. Заполните форму с валидными данными
2. Проверьте, что заявка сохранилась в админ панели
3. Убедитесь, что пришли email уведомления
4. Протестируйте валидацию с невалидными данными

## Техническая поддержка

### Частые проблемы

**Форма не отправляется:**
- Проверьте консоль браузера на ошибки JavaScript
- Убедитесь, что путь к обработчику корректен
- Проверьте права доступа к файлам

**Email не приходят:**
- Проверьте настройки SMTP
- Убедитесь, что функция `wp_mail()` работает
- Проверьте спам-папку

**Ошибки в админ панели:**
- Убедитесь, что плагин активирован
- Проверьте права пользователя
- Очистите кеш WordPress

### Логи и мониторинг
Все действия с формой логируются в стандартный лог WordPress. Для мониторинга используйте:
```php
error_log("Astarta Contact Form: " . $message);
```

2. Обновите файлы плагина
3. Проверьте совместимость с текущей версией WordPress
